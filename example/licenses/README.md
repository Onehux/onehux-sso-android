# Font licenses

`src/main/res/font/instrument_sans.ttf` and `bricolage_grotesque.ttf` are the real OneHux
Accounts brand typefaces (`frontend/src/app.css`'s `--font-body`/`--font-display`), fetched
from the [google/fonts](https://github.com/google/fonts) repository. Both are licensed under
the SIL Open Font License, Version 1.1 — see `OFL-instrument-sans.txt` and
`OFL-bricolage-grotesque.txt` in this directory for the full license text, redistributed
alongside the font files per the license's own requirement.
